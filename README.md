# ic-elatoscaloric-effect

Página de links — Iniciação Científica em Efeito Elastocalórico em Nanotubos de Carbono (IFGW/Unicamp).

Publicada via GitHub Pages a partir deste repositório.

## Ativar o GitHub Pages

1. No GitHub, vá em **Settings > Pages**.
2. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
3. Em **Branch**, selecione `main` e a pasta `/ (root)`.
4. Salve. Em alguns minutos a página fica disponível em:
   `https://medeirosdev.github.io/ic-elatoscaloric-effect/`

## Estrutura

- `index.html` — página de links
- `files/resumo-congresso-ic-2026.pdf` — resumo submetido ao XXXIV Congresso de Iniciação Científica da Unicamp

## Antes de publicar

- Adicione seu link do LinkedIn em `index.html` (procure por `data-placeholder="linkedin"`)
- Confirme se o e-mail listado é o que você quer deixar público
